# shortest-path-game
Jogo onde você deve encontrar o caminho mais curto entre dois personagens em um grafo.

## Instalação

1. Instale o Python, caso não o tenha;
2. Abra um terminal, acesse o diretório raíz do projeto, e digite `pip install -r requirements.txt`
3. Para iniciar:
   1. No Linux, use `./iniciar.sh`, e digite `http://localhost:5000` no navegador.
   2. No Windows, clique em **iniciar.bat**. O navegador abrirá automaticamente.
